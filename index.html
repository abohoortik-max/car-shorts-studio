Prepare and publish automotive short videos from a desktop workflow.

Car Shorts Studio helps creators prepare short-form automotive clips, connect their own TikTok account, review publishing settings, and send creator-authorized content through TikTok's official Content Posting API.

How it works

How it works

1. Prepare a clip. A creator selects creator-owned automotive footage and prepares a short MP4 video.

2. Connect TikTok. The creator authorizes their TikTok account through TikTok Login using the official OAuth flow.

3. Review the destination and post settings. Before a Direct Post request is initialized, the workflow retrieves the latest creator information and available publishing options from TikTok.

4. Confirm publishing. The creator reviews the caption, privacy choice, and supported interaction settings, then explicitly confirms the post.

5. Publish and check status. The video is uploaded through TikTok's Content Posting API and the workflow checks the publishing status until the request reaches a final state.

Creator authorization

TikTok access is granted by the creator through TikTok's supported authorization flow. The service does not ask creators to share their TikTok password.

Publishing controls

The publishing flow uses the destination creator's current privacy and interaction options returned by TikTok before a post is submitted.

Official API

Publishing uses TikTok's Content Posting API for creator information, Direct Post initialization, media upload, and publishing-status checks.

Creator data and control

Car Shorts Studio does not sell creator information. Authorization data, video files, captions, and publishing metadata are processed only as needed to provide the requested workflow. Creators can stop using the service and revoke TikTok authorization at any time.
